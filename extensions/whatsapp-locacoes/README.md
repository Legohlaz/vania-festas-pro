# Vânia Festas Pro — extensão WhatsApp Web

MVP de painel lateral para Chrome 114+ (Manifest V3). Para testar: abra `chrome://extensions`, ative o modo desenvolvedor, clique em **Carregar sem compactação** e selecione esta pasta. No WhatsApp Web, clique no ícone da extensão para abrir o painel.

Esta primeira versão usa dados demonstrativos e monta uma pré-reserva local. A próxima etapa é conectar a extensão a uma API autenticada do Vânia Festas Pro para usar catálogo, fotos e disponibilidade reais.
